# Tri des dossiers

Page web qui lit un export Excel (colonnes POI, Jalons, Caff, comcre) et range les dossiers par jalon (CRVT 1, APD, CRVT SUIVI, CRVT RI, ENVOI TRAVAUX, DOE, DOE RAR), puis par société et caff.

Utilisation : ouvrir `index.html` (ou le site GitHub Pages), déposer le fichier Excel, toucher une tuile.

La correspondance caff → société se modifie en bas de la page et reste enregistrée dans le navigateur.
